SHARE IN ONE TAP

好内容，随手分享。

一次安装，以后在 X 中点击分享，就能把内容收录到团队阅读库。分享无需登录；阅读内容需要管理员开通账号。

添加「分享到资讯汇集」

在 iPhone 上安装

  1. 用 Safari 浏览器打开本页，点击上方添加按钮。
  2. 在苹果页面点击获取快捷指令，再在「快捷指令」App 中点击添加快捷指令。
  3. 回到 X，打开帖子，点分享 → 分享到… → 分享到资讯汇集。菜单名称可能随版本略有不同。
  4. 第一次如提示连接本站，请选择允许。看到「已提交」即可关闭。

链接会立即保存，后台自动读取 X 公开预览、生成中文摘要和译文。稍后打开网站即可查看。

苹果链接打不开？

下载签名安装文件，在「文件」App 的下载目录点开，再添加快捷指令。

分享菜单里找不到？

打开「快捷指令」App，长按这条快捷指令 → 编辑 → 详细信息，确认「在共享表单中显示」已开启。在 X 中先打开系统分享菜单，再向下滚动寻找。

也可以直接粘贴链接

在「快捷指令」App 中点「分享到资讯汇集」，按提示输入 X 链接；也可直接输入一段文字进行翻译。

支持哪些内容？

X 帖子尝试读取免费公开预览，无法保证包含完整长文、线程、图片或视频。其他网站的链接会先保存，可在阅读库补充正文。重复链接不会重复收录。

分享内容会公开出现在本站。快捷指令只向本站提交你选择的链接或文字，文件内不含 DeepSeek 密钥。
